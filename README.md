# Portafolio Profesional — Desarrollador Web

Sitio web personal desarrollado con HTML5 semántico, CSS3 moderno modular y JavaScript Vanilla (ES6+).

## 🚀 Demo en Vivo
https://druder123.github.io/mi_portafolio/

## ✨ Características
- **Accesibilidad:** Cumplimiento de estándar WCAG AA con navegación por teclado y etiquetas semánticas.
- **Rendimiento:** Puntuación de 95+ en las 4 categorías de Google Lighthouse.
- **Modo Oscuro:** Detección de preferencia de sistema con toggle manual y persistencia en `localStorage`.
- **Diseño Responsivo:** Enfoque Mobile-First mediante CSS Grid, Flexbox y media queries.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 (Variables, Grid, Flexbox)
- JavaScript Vanilla ES6+
- Git / GitHub Pages / Netlify
